# ADR-0018: Рендеринг карты (Canvas 2D / Custom Painter)

**Дата:** 2026-09-17
**Статус:** Accepted
**Теги:** frontend, rendering

---

## Контекст

Нужно рендерить до 1000 boids, их траектории (trails), полигоны объектов-охраны, РЛС и их радиусы действия — всё на одной карте, с интерактивностью (hover, клики) и минимальной задержкой. DOM-элементы не справляются при 1000+ объектов.

## Рассмотренные варианты

1. **DOM-элементы** — просто, CSS-стили, hover/click из коробки, но медленно при 1000+.
2. **Canvas 2D + Flutter Custom Painter (выбран)** — быстрый, единый слой для всех элементов.
3. **Hybrid (Canvas + DOM overlay)** — гибкость, но сложность синхронизации координат.

## Решение

- **Рендеринг: Canvas 2D (Flutter Custom Painter) — единый слой.**
  - Один painter рендерит все элементы карты: полигоны (объекты-охраны), круги (радиусы РЛС), boids, шлейфы движения (trails), маркеры статусов.
  - Hit-testing — проверка координат на канвасе (не DOM hit-testing).
- **Интерактивность:** hover — tooltip с параметрами и статусом boid, ЛКМ — пометить опасным, ПКМ — меню статусов.
- **Оптимизация:** неактивные/остановившиеся boids не передаются по WebSocket, но сохраняются на клиенте и отображаются на карте.

## Следствия

**Положительные:**
- ✅ Единый слой рендеринга — нет десинхронизации между слоями.
- ✅ Производительность достаточна для 1000+ объектов.

**Отрицательные / риски:**
- ⚠️ Hit-testing реализуется вручную (координатная проверка).
- ⚠️ Canvas сложнее отлаживать, чем DOM.
