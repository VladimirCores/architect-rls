# ADR-0022: Хранение карт

**Дата:** 2026-09-17
**Статус:** Accepted
**Теги:** infra, data, maps

---

## Контекст

Карты — `.mbtiles` векторные тайлы. Нужно определить, где они хранятся, как обновляются и как клиент получает список доступных карт.

## Решение

- **Хранение:** файловая система сервера (для desktop — та же система). Объектное хранилище (S3/MinIO) не используется в v1.
- **Список карт:** клиент запрашивает список у сервера (`GET /maps`). Есть кнопка «обновить список».
- **Загрузка новой карты:** admin **или пользователь с правами** (feature `maps.upload`) может загрузить новую версию `.mbtiles`.
  - Новая версия **сразу перезаписывает** текущую (last-write-wins).
  - Версионирование карт в v1 отсутствует.
- **Доступность регионов** — сканирование директории карт при старте (см. ADR-0011).

## Следствия

**Положительные:**
- ✅ Простота: нет внешних зависимостей хранения.
- ✅ Загрузка новых карт доступна пользователям с правами.

**Отрицательные / риски:**
- ⚠️ Нет версионирования — при ошибочной загрузке старую карту не восстановить.
- ⚠️ Перезапись «на лету» — активные сессии могут видеть карту, которая изменилась.
