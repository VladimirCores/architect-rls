# ADR-0023: Модуль отчётов

**Дата:** 2026-09-17
**Статус:** Accepted
**Теги:** backend, reports, analytics

---

## Контекст

Нужны отчёты: индивидуальные (по пользователю) и агрегированные (по всем пользователям). Отчёты — особенность, включаемая админом через feature flags.

## Решение

- **Данные:** Event Store (события экзаменов, действий) + параметры сессии и симуляции.
  - Время в симуляции/тренинге/экзамене, результаты, количество boids, процент угаданных/пропущенных, время обнаружения по статусам.
  - Набор показателей расширяем.
- **Формат:** JSON — основной (проще), PDF — будущее.
- **Доступ:**
  - Пользователь видит только свои отчёты.
  - Admin (или пользователь с включённой особенностью `reports.see_all`) видит все отчёты.
- **Feature flags:** `reports` (доступ к модулю), `reports.see_all` (все отчёты).

## Следствия

**Положительные:**
- ✅ Единый источник данных (Event Store) — отчёты консистентны.
- ✅ Расширяемый набор показателей.

**Отрицательные / риски:**
- ⚠️ Генерация отчётов по большим объёмам событий может быть тяжёлой — требуется агрегация/кэш.
