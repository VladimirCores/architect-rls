# ADR-0012: Пайплайн карт

**Дата:** 2026-09-17
**Статус:** Accepted
**Теги:** infra, data

---

## Контекст

Для отображения карты нужны векторные тайлы. Источник — OpenStreetMap. Нужно воспроизводимо получать MBTiles из регионов Geofabrik.

## Решение

- **Пайплайн:** `Geofabrik .osm.pbf → planetiler → .mbtiles (vector)`.
- **Хранение:** файловая система сервера; перезапись без версионирования (см. ADR-0022).
- **planetiler требует JDK** — наличие в CI и на dev-машинах обязательно.
- **Параметры planetiler:** подбираются оптимально под регион.
  - Малые регионы: heap 2–4 ГБ, минуты-десятки минут; Москва с областью — `-Xmx6g`, threads=`nproc`, диск ≈ 2× выхода.
  - Россия целиком: heap 8+ ГБ, часы, десятки ГБ диска.
  - **Dev-регионы:** маленькие, 3–4 уровня зума, слои только до зданий (≈1–2 см на экране), рельеф/ландшафт не нужны.
- **GitLab CI:** результат (`.mbtiles`) сохраняется как **артефакт**. Кеш по ключу `mbtiles-{region}-{planetiler_version}-{pbf_sha256}` (sha256 загруженного `.osm.pbf` — Geofabrik меняет файлы без версий). Перед кешированием — проверка `length` и `etag` pbf; обрыв загрузки → кеш не записывается.
- **Проверка при старте dev-сервера:** наличие MBTiles региона; при отсутствии — инструкция или авто-генерация.
- **Валидация тайлов:** при запросе `/map/tiles/:z/:x/:y` — проверка границ (`z` ≤ maxZoom, `x`/`y` в пределах `2^z`). Некорректные координаты → 404.
- **README** должен явно описывать требования (JDK, место, время).

## Следствия

**Положительные:**
- ✅ Воспроизводимость.
- ✅ Кеш экономит часы CI.

**Отрицательные / риски:**
- ⚠️ Первая генерация крупного региона — дорого. Нужен явный gate в CI.

## Лицензия и атрибуция ODbL

Geofabrik `.osm.pbf` распространяется под **ODbL** (Open Database License). Вшитые `.mbtiles` в поставку приложения обязаны содержать:
- Атрибуцию OpenStreetMap и правообладателям.
- Указание лицензии ODbL.
- При распространении производных данных — на тех же условиях ODbL.

В MVP: файл `ATTRIBUTION.md` рядом с `.mbtiles`; в CI — проверка наличия файла при сборке. Frontend при первом показе карты выводит ссылку на лицензию.
