# Product Brief: RLS Simulator Trainer

## Executive Summary

RLS Simulator Trainer — десктоп-приложение для обучения операторов работе с радио-локационной станцией. Симулирует обнаружение, распознавание и маркировку движущихся объектов (boids) на карте. Оператор определяет, какой из объектов летит на охраняемую цель намеренно, и фиксирует его статусом. Приложение работает в трёх режимах — симуляция, тренировка и экзамен — и использует клиент-серверную архитектуру с едиными API-контрактами для будущей веб-версии.

## The Problem

Обучение операторов РЛС требует повторяемой, контролируемой среды, в которой можно тренировать навык распознавания опасных объектов среди потока движущихся целей. Ручное распознавание — навык, который развивается только на практике, а реальные тренировочные сценарии дороги и логистически сложны. Нет доступного десктопного инструмента, который бы моделировал работу РЛС с реалистичным поведением целей и давал бы возможность записи и воспроизведения сессий для анализа.

## The Solution

Десктопное приложение (Linux, Windows) с локальным сервером и визуализацией на карте. Основные компоненты:

- **Симуляция boids** — стайка движущихся объектов в трёх режимах: бесконечная симуляция, тренировка с таймером, экзамен с таймером и записью
- **Карта с объектами** — полигон охраняемого объекта, радиус действия РЛС, несколько РЛС и несколько целей на одной карте
- **Операторский UI** — оператор наблюдает за boids, определяет опасные по траектории, скорости и комбинации признаков, и фиксирует маркером-статусом
- **Админ-панель** — управление пользователями, ролями (оператор/админ), правами через булевы feature-флаги, CRUD справочников (RLS, boids, объекты-охраны), загрузка карт (.mbtiles)
- **Запись и реплей экзаменов** — event-sourced запись действий оператора и движения boids, воспроизведение для анализа

## What Makes This Different

- **Единый API для desktop и web** — клиент-серверные контракты идентичны будущей веб-версии; сервер может работать и локально, и в облаке с Postgres
- **Event sourcing для экзаменов** — полная запись сессии с возможностью реплея, включая движение boids и действия оператора
- **Гибкая система карт** — несколько карт в формате .mbtiles, админ загружает свои, объекты-охраны размещаются на конкретных участках карты
- **Feature-флаги** — админ управляет доступом к функциям (отчёты, статистика, загрузка карты, настройки, загрузка записи) per пользователь
- **Множественные РЛС и цели** — на одной карте может быть несколько станций и несколько охраняемых объектов; уничтожение всех РЛС = провал сессии

## Who This Serves

**Primary:** Операторы-стажёры — студенты военных училищ и сотрудники частных охранных компаний, обучающиеся работе с РЛС.

**Secondary:** Администраторы — настраивают пользователей, карты, справочники и права доступа.

## Success Criteria

- Оператор может идентифицировать и пометить опасные boids с достаточной точностью
- Экзамен формирует отчёт с процентами выявленных опасностей, пригодный для передачи внешней системе
- Записанные сессии воспроизводятся полностью (движение boids + действия оператора)
- Система поддерживает несколько карт и настраиваемые справочники (RLS, boids, объекты-охраны)
- Роли и feature-флаги корректно ограничивают доступ к функциям

## Scope

**In (MVP):**
- Десктоп-клиент (Linux, Windows) с локальным сервером
- Симуляция boids в 3 режимах (симуляция, тренировка, экзамен)
- Карта с полигонами, РЛС, boids, отображение радиуса действия
- Операторский UI для маркировки boids статусами
- Роли: оператор (ограниченный функционал) и админ (полный)
- CRUD справочников: RLS, boids, объекты-охраны
- Система карт (.mbtiles) с выбором из доступных и загрузкой новых
- Запись экзаменов и реплей
- Feature-флаги для управления доступом к функциям

**Out (future):**
- Веб-версия (API-контракты готовы, клиент отдельно)
- Аналитика и статистика
- Экспорт результатов
- Настройки приложения
- Интеграции
- Криптографическая подпись событий экзамена

## Vision

Платформа для подготовки операторов РЛС, которая растёт от десктопного тренажёра до полноценной онлайн-системы с централизованной аналитикой, отчётностью и интеграцией с внешними системами учёта и контроля.
